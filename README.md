# 서울: 마지막 주파수 — SEC 01 양재동 → 양재천 (vertical slice)

HD pixel-art side-scroller slice, WebGL (Three.js) + Vite.

- Play: https://aipie-admin.github.io/seoul-last-frequency-demo/
- All pixel art is code-generated (`scripts/px/`), raster assets are WebP only.
- Build: `npm i && python3 scripts/px/chars.py && python3 scripts/px/env.py && npx vite build`
- Fonts: Galmuri (SIL OFL 1.1), IBM Plex (SIL OFL 1.1).
